# Glossary (German -> English)

Terms as used in the handbook (`docs/handbook/handbuch.md`, cited `H p.N`) and readme (`docs/handbook/readme.md`, cited `R p.N`). Spec files use the English term and give the German in parentheses on first use.

## Places and structure
| German | English | Notes |
|---|---|---|
| Fürstentum Mittelland | Principality of Mittelland | the whole country, H p.40 |
| Grafschaft | county | 3: Mooringen, Auenthal, Bergenhöh, H p.40 |
| Stadt / Städte | city / cities | 10, H p.6 |
| Niederlassung | branch (trading post) | one per city per human player, H p.10 |
| Niederlassungsrecht | branch rights | sold to only one human player per city, H p.10 |
| Kontor | office | hub screen of a turn, H p.9 |
| Lager / Lagerraum | warehouse / storage space | m², H p.15 |
| Holzlager / Steinlager | wooden / stone storage | H p.15 |
| Wohnsitz | residence | H p.15 |
| Zollburg | toll castle | 3, one per county, H p.21 |
| Räuberlager | robber camp | 4, H p.21, p.40 |
| Kasematten | casemates | capacity expansion of a toll castle, H p.24 |
| Strohlager | straw camp | capacity expansion of a robber camp, H p.24 |
| Großer See | Great Lake | centre of map, H p.40 |
